# THE TREND EDIT

국내외 패션·라이프스타일 매체의 공식 RSS를 모아 분류·분석하는 개인용 트렌드 매거진 대시보드.

## 사용법

| 할 일 | 방법 |
|---|---|
| 지금 수집 | `run_collect.bat` 더블클릭 (또는 `python collect.py`) |
| 대시보드 보기 | `index.html` 더블클릭 (브라우저에서 열림, 서버 불필요) |
| 3시간마다 자동 수집 | PowerShell에서 `.\setup_schedule.ps1` 한 번 실행 |
| AI 한국어 요약 켜기 | 환경변수 `ANTHROPIC_API_KEY` 설정 후 수집 |
| 매체 추가 | `sources.py`에 한 줄 추가 (공식 RSS 주소) |
| 브랜드·관심사 추가 | `taxonomy.py`의 `BRANDS` / `TAGS` 수정 |

## 온라인 배포 (GitHub Actions + Pages)

`.github/workflows/collect.yml`이 3시간마다 클라우드에서 `collect.py`를 실행하고, 누적 데이터를 커밋한 뒤 GitHub Pages로 배포한다. PC가 꺼져 있어도 갱신된다.

- 수동 실행: 저장소 Actions 탭 → collect-and-deploy → Run workflow
- AI 요약: 저장소 Settings → Secrets and variables → Actions 에 `ANTHROPIC_API_KEY` 추가
- 로컬에서 작업할 때는 먼저 `git pull` (봇이 데이터를 계속 커밋하므로)

## '실시간'의 정의

이 대시보드의 실시간은 **3시간 주기 폴링**입니다. 각 매체의 RSS는 최근 10~50건만 제공하므로, 주기 사이에 50건 넘게 발행하는 매체는 일부를 놓칠 수 있습니다. 대상 매체 대부분은 하루 10~50건을 발행합니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `sources.py` | 매체 등록부 (섹션·지역·RSS 주소, 수집 불가 사유) |
| `taxonomy.py` | 관심사 태그 19개, 브랜드 사전 |
| `collect.py` | 수집 → 분류 → 중복 통합 → 랭킹·리포트 → `data/data.js` 생성 |
| `index.html` | 대시보드 (피드·트렌드·브랜드·국가 비교·리포트·북마크·매체 현황) |
| `data/store.json` | 누적 저장소 (최근 90일) |
| `data/collect.log` | 자동 수집 로그 |

## 데이터 원칙

- 공식 RSS만 사용. 제목·발행일·이미지 주소·짧은 미리보기(220자)만 저장하고 기사 전문은 저장하지 않음
- 이미지는 원 매체 서버에서 직접 표시, 모든 카드는 원문으로 연결
- 발행일 없는 항목은 게시하지 않음
- 증감(▲▼)은 비교 구간 전체를 실제로 수집한 뒤부터 표시 (수집 초기에 '급상승'이 부풀려지는 것 방지)
- AI 요약·해설에는 항상 표시가 붙고, RSS 미리보기 범위 안의 사실만 쓰도록 지시

## 알려진 한계

- 무신사 매거진: 공개 RSS 없음 → 수집 불가, 매체 현황에 링크만 표시
- 중복 통합은 제목 단어 비교 방식이라 **같은 언어끼리만** 묶임 (예: Hypebeast 영문판과 한국판의 같은 기사는 별도 노출)
- 이슈명 추출은 영어 고유명사 기준. 한국어·일본어 기사의 이슈는 브랜드 사전·카테고리로만 잡힘 (AI 키워드를 켜면 보완됨)
